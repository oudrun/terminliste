# WordPress-plugin for terminliste

Denne mappen inneholder en WordPress-versjon av løsningen.

## Installer

1. Kopier mappen `terminliste-hundeprover` til `wp-content/plugins/`
2. Aktiver pluginen i WordPress-admin
3. Opprett en side og legg inn shortcoden `[terminliste_hundeprover]`
4. Vedlikehold prøver fra adminmenyen `Terminliste`

## Innhold

- front-end visning av prøver og klasser
- påmeldingsskjema for deltakere
- administrasjon i WordPress for prøver, klasser og påmeldinger
